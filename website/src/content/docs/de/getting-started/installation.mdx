## Systemvoraussetzungen

Je nach Ihrer Plattform müssen Sie eventuell die Bibliotheken des `mpv`-Medien-Frameworks installieren:

### Windows & macOS

**Keine manuelle Einrichtung erforderlich!** Die vorkompilierten Pakete für Windows und macOS enthalten bereits alle erforderlichen `libmpv`-Bibliotheken direkt im Anwendungsbundle, zusammen mit dav1d für die AVIF-Bildunterstützung und ffmpeg für schnellere Video-Miniaturansichten.

### Linux

Media Sort ist für Linux sowohl als Snap als auch als AppImage verfügbar.

#### Snap (empfohlen unter Ubuntu)

Media Sort wird als Snap mit klassischer Confinement im [Snap Store](https://snapcraft.io/media-sort) veröffentlicht. Die klassische Confinement ist erforderlich, da die App – genau wie das AppImage – Dateien überall im Dateisystem sortiert und sich das mit strikt eingeschränkten Schnittstellen nicht abbilden lässt. Das Snap enthält `libmpv`, `libdav1d`, `ffmpeg` und ALSA-Unterstützung, sodass keine zusätzlichen Laufzeitbibliotheken benötigt werden:

```bash
sudo snap install media-sort --classic
```

Aktualisierungen werden automatisch von snapd bereitgestellt. Die `.snap`-Datei ist außerdem an jedes [Release](https://github.com/Lolle2000la/Media-Sort/releases) angehängt und kann offline installiert werden:

```bash
sudo snap install ./media-sort_*_amd64.snap --classic --dangerous
```

#### AppImage

Die AppImage-Pakete laufen dynamisch im Host-System und setzen die Installation von `libmpv` und `libdav1d` (für die AVIF-Bilddecodierung) voraus. Das AppImage benötigt außerdem `libasound2` sowie X11-/Wayland-Bibliotheken, die auf Desktop-Linux-Distributionen üblicherweise bereits vorinstalliert sind.

Die Installation von `ffmpeg` ist unter Linux optional — sie ermöglicht schnellere Video-Miniaturansichten, wobei Media Sort ansonsten auf mpv zurückfällt.

#### Arch Linux / CachyOS

```bash
sudo pacman -S mpv dav1d
```

#### Debian / Ubuntu

```bash
sudo apt install libmpv2 libasound2 libdav1d7
```

#### Fedora

```bash
sudo dnf install mpv-libs dav1d-libs
```

:::note
Wenn `libmpv` nicht installiert ist, startet Media Sort dennoch und funktioniert für Bilder und Audio. Die interne Video- und GIF-Wiedergabe wird automatisch deaktiviert. Videodateien werden jedoch weiterhin erkannt und können durchsucht werden, allerdings ohne Miniaturansichten.
:::
