## System Prerequisites

Depending on your platform, you may need to install the `mpv` media playback engine libraries:

### Windows & macOS

**No manual setup is needed!** The precompiled packages for both Windows and macOS automatically bundle all required `libmpv` libraries natively inside the application bundle, along with dav1d for AVIF image support and ffmpeg for fast video thumbnails.

### Linux

Media Sort for Linux ships both as a Snap and as an AppImage.

#### Snap

Media Sort is published to the [Snap Store](https://snapcraft.io/media-sort). It bundles `libmpv`, `libdav1d`, `ffmpeg` and ALSA support, so no extra runtime libraries are needed:

```bash
sudo snap install media-sort
```

<SnapBadge />

The snap is strictly confined, so it sorts anything under your home directory. To also sort files on external drives (`/media`, `/mnt`), connect the `removable-media` interface once:

```bash
sudo snap connect media-sort:removable-media
```

Audio plays through the sound server (PipeWire/PulseAudio) out of the box. On a system with no sound server, connect the raw-ALSA interface:

```bash
sudo snap connect media-sort:alsa
```

Updates are delivered automatically by snapd.

The `.snap` files are also attached to every [release](https://github.com/Lolle2000la/Media-Sort/releases) for offline installation.

#### AppImage

The AppImage packages run dynamically on the host environment and require `libmpv` and `libdav1d` (for AVIF image decoding) to be installed on your system. The AppImage also depends on `libasound2` and X11/Wayland libraries which are typically pre-installed on desktop Linux distributions.

Installing `ffmpeg` is optional on Linux — it enables faster video thumbnails, but Media Sort falls back to mpv when it is not present.

#### Arch Linux / CachyOS

```bash
sudo pacman -S mpv dav1d
```

#### Debian / Ubuntu

```bash
sudo apt install libmpv2 libasound2 libdav1d7
```

#### Fedora

```bash
sudo dnf install mpv-libs dav1d-libs
```

:::note
If `libmpv` is not installed, Media Sort will still launch and function for images and audio. In-app video and GIF playback will be automatically disabled. Video files are still detected and browsable, though thumbnails will not be available for them.
:::
